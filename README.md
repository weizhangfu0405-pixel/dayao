# 大曜 · 武道王朝

> 九州东陆，武道为尊。一位大宗师可镇一州，一位天人可压一国。
> 而你手里，是立国三百二十年的社稷。

一款跑在浏览器里的**王朝经营 × 文字权谋**游戏。你是大曜第七位皇帝，年号永昌，在位二十七年：北边铁勒的第十九个冬天要来了，太子未立，江湖上最后一位宗师去年病故。

每下一道旨意，由 DeepSeek 推演后果——**你想不到的那种后果**。

## 在线游玩

**https://weizhangfu0405-pixel.github.io/dayao/**

第一次进入，点右上角 **「设」**，填入你自己的 DeepSeek API Key。没有 Key 也能玩：点 **「以推演司试玩」**，走内置的离线规则引擎。

## 怎么玩

```
开国 → 抉择（甲/乙/丙/丁） → 史官落笔 → 翻篇 → 下一场朝会
```

- 六项国势：**国运、民心、国库、军力、武运、威望**。国运归零即亡国。
- 每个选项都带倾向：**怀柔 / 铁血 / 权谋 / 奇诡 / 守成**。
- 都不满意就点 **「另辟蹊径」**，自己写一道旨意（60 字以内）。AI 照办，也照实反噬。
- 三种结局：**亡国**（国运归零）、**盛世**（国运 ≥ 92 时封禅）、**落幕**（永昌四十五年传位）。
- 进度自动存在浏览器里，下次打开可以「续卷」。

## 世界观

九州东陆，武道为尊。武夫九品：淬体、易骨、开脉、凝罡、换血、化劲、通玄、宗师、大宗师；大宗师之上是「天人」，三百年只出过七位。

格局参照《雪中悍刀行》的**庙堂 + 江湖**：武道气运有限，强者愈强则天下愈薄，所以王朝之中强者不过数人，而每一位的去留都是国运级别的变量。**人物、地名、境界、事件与全部文本均为原创**，未使用原作文本。

## 关于密钥（请读）

这是一个**纯静态站点**，没有后端、没有账号、没有埋点：

- 你的 API Key 只写进**你自己浏览器的 localStorage**；
- 每次推演由你的浏览器**直连 `api.deepseek.com`**，不经过任何第三方服务器；
- 其他人的 Key 与你的互不可见；换设备或清缓存后需重新填写；
- 想撤销：游戏内「设」→「抹去」。

## 本地运行

```sh
git clone https://github.com/USER/dayao.git
cd dayao
npx serve .          # 或任意静态服务器
```

> ES Module 必须走 http(s)，直接双击 `index.html`（file://）打不开。

## 技术

纯前端：无框架、无构建、无依赖。四个模块：

```
index.html     结构
style.css      水墨/金/朱砂 样式，移动端优先
app.js         状态机、渲染、存档
lib/api.mjs    DeepSeek 调用 + 输出校验（数值夹取、结局守卫）
lib/prompts.mjs 世界设定与史官提示词
lib/fallback.mjs 推演司（离线规则引擎，六个危机十八种走向）
```
